## 開き方

### 方法1: ローカルサーバーで開く (推奨)

ブラウザでローカルファイルを開くとESモジュールがCORSで弾かれる場合があるため、簡易サーバー経由で開いてください。

**Python (どのPCにもだいたい入っています):**
```bash
cd shigedenki-toppage
python3 -m http.server 8000
```
→ ブラウザで http://localhost:8000 を開く

**Node.js (お持ちの方):**
```bash
cd shigedenki-toppage
npx serve .
```

### 方法2: ブラウザで直接開く

`index.html` をブラウザで直接ダブルクリック。
※ Chrome系では一部の機能が動かない場合があります。その場合は方法1で。

## 実装済みアニメーション一覧

### ローディング画面
- ロゴが拡大しながらフェードイン
- 「SHIGE DENKI」テキストが遅れて表示
- 横線がスーッと伸びる
- 2.6秒後に全体がフェードアウト

### ヘッダー (固定)
- 初期表示時に上からスライドイン
- スクロール時に背景透明 → 白に変化 (ブラー付き)
- ナビホバーで下線がスライド + 色変化

### Hero (ファーストビュー)
- 背景画像が4枚クロスフェード (5.5秒ループ)
- 背景画像にKen Burnsズーム効果
- メインコピーが行単位で下からせり上がり (stagger)
- サブコピー・CTAボタンが順番にフェードイン
- 下部の SCROLL ヒントが線で上下にループ
- CTAボタンホバーで色がスライド変化 + 矢印が動く

### Stats (数字でわかる)
- スクロール到達で数字がカウントアップ
- 各カードが順番にフェードアップ

### Reasons (選ばれる3つの理由)
- 3カラムが左から順に出現
- 番号が大きな英文字で表示

### Services (対応工事8工種)
- グリッド形式
- ホバーで背景色変化 + アイコン回転 + 下線スライド

### Works (施工事例)
- メイン事例の写真がホバーでスムーズに拡大
- 8枚の写真ギャラリーがスクロールに合わせてランダムに出現
- 各画像ホバーでズーム + 明度up

### Trust (信頼の証)
- 4ブロックが順次フェードイン

### CEO Message
- 写真にスクロール連動のパララックス効果
- メッセージが順番にフェードイン

### Recruit
- セージグリーン背景に円形装飾
- ボタンホバーで色が下から塗りつぶしアニメーション

### Contact
- 3カードが順次フェードイン
- ホバーで背景色変化 + 上部に色アクセント

### フッター
- ナビホバーで左にスライド
